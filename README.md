# Deal Hunter

Find limited-time free games on Steam, Epic, GOG, itch.io, and mobile stores.
The website and Android app share one interface: compact and grid layouts,
countdowns, a watchlist, claimed-game tracking, savings, and a folding scan summary.

## How Updates Work

GitHub Actions runs `update_data.js` every 30 minutes and publishes `data/deals.json`.
Scheduled runs may be delayed by GitHub. Collectors discover offers automatically;
game entries are not maintained manually.

Android displays its saved snapshot immediately and fetches the published feed
on launch and return to the foreground. A native Android JobScheduler service
refreshes its saved feed and widget approximately every 30 minutes without an open app.
Android may defer jobs during Doze or battery restrictions. Force-stopping the app can
prevent jobs from running until the app is opened again.

The widget shows artwork, store, title, and expiry for a rotating selection of active
offers. Tapping a deal focuses it in the app. Previous/next buttons are available.

## Coverage

Direct collectors cover Steam, Epic, GOG, and itch.io. Additional discovery uses the
[GamerPower API](https://www.gamerpower.com/api-read), with attribution to
[GamerPower](https://www.gamerpower.com).

The supplemental collector also recognizes Ubisoft, EA, Fanatical, Humble, and IndieGala
store links. These partner offers require a paid value, an end date, and a matching store
domain. Trials, free weekends, raffles, subscriptions, and purchase requirements are
excluded. An empty provider section means no qualifying offer was detected; it does
not mean the app scans every item in that publisher's catalog. Regions and available
key supplies can affect redemption.

## Development

Use Node.js 22 or later.

```sh
npm ci
npm test
npm start
```

Open `http://localhost:5001`. Express provides live collection, price search,
and sponsorship endpoints. GitHub Pages reads the automatically published static feed.

## Android Build

Requires JDK 17 and the Android SDK. Configure `android/local.properties` with your SDK
path; this machine-specific file is excluded from Git.

```sh
npm run mobile:sync
cd android
./gradlew :app:assembleDebug
```

The package remains `com.milak.dealhunterfresh`, with the DealHunter name and yellow
lightning icon. The resulting APK is a debug testing build. Google Play publication
requires a separately signed production build.

`index.html` is the interface source for both platforms. `mobile_web/` and Android's
copied web assets are generated by the sync command and are not committed.

## Sponsorship

`data/ads.json` controls the existing sponsored slot. Its example campaign is a template;
it does not connect to an advertiser payment system or an ad network. Express records
impressions and clicks locally; GitHub Pages alone does not provide those server endpoints.
